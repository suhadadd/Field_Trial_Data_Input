Pengaturan sinkronisasi

Tempel URL Web App dari Google Apps Script setelah backend dipasang.

Catatan keamanan

Gunakan spreadsheet khusus penelitian. Jangan menaruh password atau kredensial rahasia di aplikasi. Batasi akses spreadsheet kepada petugas yang berwenang.

Alur pemasangan

  1. Buat Google Spreadsheet kosong.
  2. Buka Ekstensi → Apps Script.
  3. Salin isi file apps_script.gs dari paket ini.
  4. Jalankan fungsi setupDatabase satu kali dan berikan izin.
  5. Deploy sebagai Web App, lalu salin URL /exec ke sini.
  6. Host folder PWA melalui HTTPS (misalnya GitHub Pages).
